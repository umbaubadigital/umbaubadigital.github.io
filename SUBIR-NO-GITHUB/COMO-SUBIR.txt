COMO SUBIR O SITE NO GITHUB (uma parte de cada vez)
========================================================

Endereço: github.com/umbaubadigital/umbaubadigital.github.io

Para CADA parte, na ordem:
  1. No GitHub, clique em  Add file  >  Upload files.
  2. Abra a pasta da parte (nesta mesma pasta SUBIR-NO-GITHUB).
  3. Entre nela, aperte Ctrl+A (seleciona tudo) e ARRASTE para a área do GitHub.
     Arraste o que está DENTRO da pasta da parte, não a pasta da parte em si.
  4. Confira se a lista mostra os arquivos com as pastas (ex.: servicos/marca/index.html).
  5. Role até o fim e clique no botão verde  Commit changes.
  6. Avise o Claude. Ele confere se chegou antes de você seguir para a próxima parte.
